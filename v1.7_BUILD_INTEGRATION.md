### 3. Build System Updates Needed:

#### VolkDMA.vcxproj.filters - Add to ItemGroup (ClInclude):
```xml
    <ClInclude Include="include\VolkDMA\batch.hh">
      <Filter>include\VolkDMA</Filter>
    </ClInclude>
```

#### VolkDMA.vcxproj.filters - Add to ItemGroup (ClCompile):
```xml
    <ClCompile Include="src\batch.cpp">
      <Filter>src</Filter>
    </ClCompile>
    <ClCompile Include="src\dma_batch_integration.cpp">
      <Filter>src</Filter>
    </ClCompile>
    <ClCompile Include="tests\batch_test.cpp">
      <Filter>tests</Filter>
    </ClCompile>
```

#### CMakeLists.txt - Add to sources:
```cmake
# v1.7 - Batch Operations
add_library(volkdma_batch
    include/VolkDMA/batch.hh
    src/batch.cpp
    src/dma_batch_integration.cpp
)

target_link_libraries(volkdma_batch
    PUBLIC volkdma_core
)

# Tests
add_executable(batch_test tests/batch_test.cpp)
target_link_libraries(batch_test volkdma_batch)
```
