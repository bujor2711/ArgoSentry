## 🔧 **BUILD SYSTEM INTEGRATION**

### **Visual Studio (VolkDMA.vcxproj.filters)**

Add these entries to your `.vcxproj.filters` file:

```xml
<!-- In <ItemGroup> for ClInclude -->
<ClInclude Include="include\VolkDMA\health.hh">
  <Filter>include\VolkDMA</Filter>
</ClInclude>

<!-- In <ItemGroup> for ClCompile -->
<ClCompile Include="src\health.cpp">
  <Filter>src</Filter>
</ClCompile>

<ClCompile Include="src\dma_health_integration.cpp">
  <Filter>src</Filter>
</ClCompile>

<ClCompile Include="tests\health_test.cpp">
  <Filter>tests</Filter>
</ClCompile>
```

Update your `CMakeLists.txt`:


## 🎯 **USAGE EXAMPLE**

```cpp
#include "VolkDMA/dma.hh"
#include "VolkDMA/health.hh"

// Enable health monitoring
VolkDMA::DMA dma;
dma.enable_health_monitoring(true);

// Run manual health checks
dma.run_health_checks();

// Get overall status
auto status = dma.get_health_status();
if (status != VolkDMA::HealthStatus::Healthy) {
    std::cout << "Warning: " << dma.get_health_summary() << "\n";
}

// Start automatic monitoring (checks every 30 seconds)
dma.start_automatic_health_monitoring(std::chrono::seconds(30));

// ... use DMA normally ...

// Stop monitoring when done
dma.stop_automatic_health_monitoring();
```
